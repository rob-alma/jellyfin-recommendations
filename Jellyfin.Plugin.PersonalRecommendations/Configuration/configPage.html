Personal Recommendations

Builds a per-user taste profile from watch history (genres, cast, crew, studios) and shows a "Recommended For You" row on the home screen for every user.

Keeps one franchise or studio from filling the whole list. 0 disables the cap.

Home screen widget

Cosmetic only: the first time recommendations are computed for an account with zero favorites of its own, marks its top 3 recommendations as favorites so Jellyfin's own Favorites tab isn't empty. Never touches an account that already has even one favorite, and only ever runs once per account.
How the widget's script gets loaded into the web client. Automatic tries the File Transformation and JavaScript Injector plugins first (if installed), then falls back to patching index.html directly. Changing this takes effect after a server restart.

Refresh schedule

Also runs on demand from Dashboard > Scheduled Tasks > Personal Recommendations.
Off by default - the scheduled refresh above is enough for most setups. Turn this on for fresher recommendations right after someone finishes watching something, at the cost of extra refreshes scattered through the day instead of only on the schedule.
